# Mermaid.js
## Flowchart
Use flowchart id mermaid using alphabet e.g. A to Z, AA to ZZ, AAA to ZZZ, etc

### List shapes and mermaid code
| Semantic Name | Mermaid Code   |
| ------------- | -------------- |
| Database      | id[("text")]   |
| Subprocess    | id[["text"]]   |
| Process       | id["text"]     |
| Event         | id("text")     |
| Start         | id(("text"))   |
| Stop          | id((("text"))) |
